# 🩺 Zyra Hospital – Doctor Appointment System (Phase 1)

Zyra Hospital's Doctor Appointment Web App is a modern, responsive, and patient-first solution for scheduling, rescheduling, and managing appointments — built with React, Zustand, Material UI, and FullCalendar.

---

## 🚀 Features

- 🩺 Doctor listing with specialties and availability
- 📆 Calendar view of scheduled appointments
- ✅ Real-time form validation and error handling
- 🔄 Reschedule existing appointments with preserved time slots
- 💡 Smart filtering and dynamic data via Zustand (state like localStorage)
- 📱 Fully responsive and optimized for mobile & desktop

---

## 🧱 Tech Stack

- **Frontend:** React.js, Material UI (MUI), Framer Motion
- **State Management:** Zustand (with persist)
- **Calendar UI:** FullCalendar React
- **Routing:** React Router v6
- **Deployment:** Vercel (live on production branch)
